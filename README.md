# Hostel Rent Management Portal

> A full-stack hostel billing system - C# API + Vanilla JS Portal



**Live Frontend:** https://is-project-2026.github.io/rent-management-168879/  
**Live C# API:** https://rent-management-168879.onrender.com  
**Repo:** https://github.com/IS-PROJECT-2026/rent-management-168879

---

### ✨ Features

- **Auth:** Login / Register with room type
- **Dashboard:** Rent / Power / Water paid, balance, last paid date
- **Pricing Engine:** Per room type (Twin, Cluster, Studio, Premium)
- **Payments:** Separate bill pay - C# controller updates balance
- **UX:** Button spinners for Render cold-start

### 🏠 Room Pricing

| Room | Rent | Power | Water |
|------|------|-------|-------|
| Twin | 3000 | 2000 | 1000 |
| Cluster | 4000 | 3000 | 2000 |
| Studio | 5000 | 4000 | 3000 |
| Premium | 6000 | 5000 | 4000 |

### 🛠️ Tech Stack

**Frontend:** HTML5, CSS3, Vanilla JS (Fetch API), Deployed on GitHub Pages  
**Backend:** **C# .NET 8 / ASP.NET Core Web API**, Controllers + Models, JSON persistence  
**DevOps:** GitHub Actions (`deploy.yml`), Render (Dockerfile), Git
